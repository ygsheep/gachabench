海风带着咸腥味掠过桅杆，发出呜呜的声响，像是什么人在远处低声啜泣。

他扶着船舷，指节因为用力而发白。脑海里那些不属于他的记忆仍在翻涌——蒸汽与机械的轰鸣、高耸入云的烟囱、还有一声又一声冗长的汽笛。

「该回去了。」她说，「今晚的值守，还没轮到你了。」

尚未接入

          
这是整合方案第 3 层的入口。落地之后：搜书名 → 选书源 → 看目录 → 收正文 → 进原著库，中间不用手改。

          

            
01依赖+6 个后端包（lxml / cssselect / jsonpath-ng / quickjs…），dist 体积 +15~45MB，打包脚本要补 hiddenimports。

            
02合规来源标注 + 免责声明，默认关闭；字体解密不做。

            
03边界只到「文本」——改编成 §①–§⑥ 提示词仍是外面那一步的活。

设置

          
改完点各组的「保存」。目录名类改动会影响后续扫描与落位，不会搬动已有文件。

        

      

      

        

          
连接
