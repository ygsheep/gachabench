# P8 收尾与下线

依赖：P0–P7 全部通过。

## 目标

删掉过渡代码，把性能、诊断与打包补齐，让安装包在干净机器上能启动、能建库、能索引、能把一段从分镜跑到提示词再到审片。P8 结束才算 v1 完成。

## 进入条件

- 五个页面都走新路由，旧页面的入口只剩重定向。
- 后端新旧两套数据访问并存已确认没有写冲突。
- 打包脚本能在开发机产出安装包。

## 范围

| 做 | 不做 |
| --- | --- |
| 旧路由与旧页面下线 | 不做 v2 账本同步 |
| 性能与体积收敛 | 不做多语言 |
| 诊断包与日志规范 | 不做云备份 |
| 启动握手、健康检查、退出流程 | 不做自动更新 |
| 打包冒烟与干净机验证 | 不做代码签名 |

## 步骤

1. 下线旧代码：

- 删除 `backend/routers/` 中已被新模块替代的路由，保留 `/api/health` 与工作区入口；
- 删除 `backend/splitter.py`、`backend/prompt_locator.py` 的薄封装，旧测试改为直接测新模块；
- 删除前端 `src/pages/` 中已替换的页面与 `store/useApp.ts` 的筛选残留；
- 删除 P0 的旧链接重定向，保留一个版本后统一移除。

2. 统一数据访问：旧 `db.py` 与手写 `_MIGRATIONS` 在旧表访问全部改完后删除，只留 Alembic。确认 `SCHEMA` 中的每个旧表都有对应模型与 baseline。

3. 启动流程：

- Tauri 生成随机令牌与端口，spawn sidecar，读 stdout 握手；
- sidecar 打开库、跑迁移、启动监听，5 秒内未握手视为失败；
- 窗口加载后请求 `/api/health`，失败显示启动失败页与日志路径；
- 退出时先请求 `/api/shutdown`，3 秒未退出则终止进程。

4. 本地安全：

- 后端只绑 `127.0.0.1`；
- 除 `/api/health` 外校验 `X-Session-Token`；
- CORS 只允许 Tauri 与开发来源；
- 媒体与缩略图接口先 `resolve` 再判断是否在工作区根下；
- 密钥只进凭据管理器，接口与日志只留掩码。

5. 性能收敛，目标值：

| 项 | 目标 |
| --- | --- |
| 一万文件工作区的首屏资产列表 | 1s 内返回第一页 |
| 索引全量扫描 | 一万文件 5 分钟内完成 |
| 段页打开 | 500ms 内出中间层首个视图 |
| 40KB 正文渲染与差异 | 1s 内 |
| 路由切换 | 200ms 内出现骨架 |
| SSE 断线重连 | 3s 内恢复 |

达不到时先查索引写入批大小与前端请求瀑布，不加缓存层糊过去。

6. 诊断包：设置页导出 zip，内容为版本、配置掩码、最近 200 条日志、`PRAGMA integrity_check` 结果、索引统计、最近 20 条失败任务。不包含正文与媒体。

7. 日志：统一 jsonl，字段为时间、级别、模块、事件、耗时、traceId；慢请求超过 500ms 单独记一条；日志保留 7 天，按天切分。

8. 打包：

- PyInstaller onedir 带上 `modules/prompts/templates`、`migrations`、`alembic.ini`、ffmpeg 二进制；
- Tauri `resources` 带上后端产物，`bundle.targets` 保持 `nsis`；
- 安装包首次启动在干净目录建库并完成一次索引；
- 卸载不删工作区。

9. 回归矩阵：

| 场景 | 判定 |
| --- | --- |
| 全新机器安装 | 启动无白屏，能新建工作区 |
| 打开旧工作区 | 不迁数据，能读到旧卡片 |
| 工作区含中文与空格路径 | 索引、改名、播放均正常 |
| 工作区在移动硬盘 | 拔盘后提示只读，插回恢复 |
| 磁盘满 | 写入失败并提示，不损坏库 |
| 后端崩溃 | 壳自动重启最多三次，仍失败给诊断包入口 |
| 10000 个文件 | 列表、搜索、扫描满足上表目标 |

10. 文档与版本：更新 `README.md`、`docs/ARCHITECTURE.md` 的落地状态，版本号在安装包、`/api/health`、`package.json` 三处一致。`docs/REDESIGN-PRD.md` 的十条验收逐条对照，未通过的写明原因。

## 风险与回退

下线旧代码是单向动作。删除前打 tag，保留一个可回退提交；旧库结构不删列，只删代码，降级版本仍能打开。

打包最容易漏模板与迁移文件。构建脚本里加一段校验：启动后检查 templates 目录与 `alembic_version` 表存在，缺一项直接失败，不产出安装包。

安全校验加上后，开发期浏览器直连需要单独放行 `localhost:5173`，这个来源只存在于开发配置，不进入安装包。
